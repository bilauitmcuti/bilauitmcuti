# Bila UiTM Cuti - Academic Calendar

This file is intended for LLM indexing and summarization.
Primary site: https://bilauitmcuti.com
Project type: UiTM academic calendar web app for students.

## One-line summary
Bila UiTM Cuti helps UiTM students check academic dates (registration, lectures, exams, and breaks) by program and session without relying on multiple PDFs.

## What the app does
- Shows UiTM academic calendar data in grid and list views with activity filters and countdown to the next activity.
- Supports program-specific schedules: Foundation/Professional, Pre-Diploma, Diploma, Diploma (Part-Time), Bachelor, Bachelor (Part-Time), Master, and PhD.
- Includes Group A and Group B schedule differences.
- Handles regional date variations for Kedah, Kelantan, and Terengganu (KKT).
- Links to an AI chat assistant at /chat (separate app on the same site) for calendar and general UiTM questions.
- Installable PWA with offline-friendly service worker and light/dark themes.
- Links to Find My Internship for discovering internship opportunities from multiple sources across Malaysia.

## Intended users
- UiTM students who need fast semester planning.
- UiTM community members looking for a simpler calendar reference.

## Stack
- Next.js 16 (App Router, edge runtime) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui (Base UI) + Hugeicons + Geist
- Cloudflare Pages (`@cloudflare/next-on-pages`)
- Cloudflare Turnstile (bot protection on feedback)
- Cloudflare Zaraz → Google Analytics 4 (usage analytics; no gtag.js in the client bundle)
- Service worker (PWA support)
- pnpm

## Data source
Calendar and related schedule data come from the public Bila UiTM Cuti API (`https://api.bilauitmcuti.com`).
The browser uses same-origin routes (`/api/v1/meta`, `/api/v1/calendar`); upstream requests stay server-side.

## Privacy and security notes
- No user accounts.
- No personal profile storage.
- Analytics via Cloudflare Zaraz and Google Analytics 4.
- Security reporting: https://bilauitmcuti.com/feedback and hello@bilauitmcuti.com

## Main pages
- / : main calendar (grid)
- /list : list calendar view

- /chat : AI assistant (separate app; linked from this calendar)
- /download : PWA install instructions
- /feedback : feedback and report form (/contact redirects here)
- /about : project details, terms, and disclaimer
